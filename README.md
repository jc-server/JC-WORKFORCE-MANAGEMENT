# Jaiswal Workforce Management System

A complete workforce management system built with Supabase and GitHub Pages.

## Features

- 🔐 Secure authentication with Supabase Auth
- 👷 Worker management (Add, Edit, Delete)
- 📅 Daily attendance tracking (Present/Absent/Half-day)
- 💰 Financial management (Wages, Advances, Payments)
- 📊 Dashboard with real-time statistics
- 📈 Monthly attendance calendar view
- 🎨 Modern, responsive UI

## Deployment

This app is deployed to GitHub Pages. Visit: `https://YOUR_USERNAME.github.io/jaiswal-workforce/`

### Setup

1. Clone the repository
2. Create a Supabase project
3. Run the migrations in `/supabase/migrations/`
4. Update `src/config/supabase.js` with your credentials
5. Push to GitHub
6. Enable GitHub Pages in your repository settings

## Tech Stack

- **Frontend**: Vanilla JavaScript (ES Modules)
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Hosting**: GitHub Pages
- **CDN**: Supabase JS Client
